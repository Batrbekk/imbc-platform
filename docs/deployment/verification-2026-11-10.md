# Проверка Azure dev-стенда: 10 ноября 2026

Среда: `imbc-dev` в `imbc-dev-rg`, Poland Central. Адрес и обслуживание — в [azure-dev.md](azure-dev.md).

## Сборки и автоматические проверки

Прошли 45 тестов API (16 интеграционных на отдельной PostgreSQL 18), 23 contracts и 4 web; TypeScript, web lint и production-сборки API, Next.js и identity-темы. Compose, Caddy и deployment-скрипты проверены; миграции завершились успешно.

## Проверки на сервере

- HTTPS с действующим сертификатом, готовность сервисов, закрытые порты данных и защищённый Mailpit.
- OIDC Code + PKCE, защищённые cookies, почтовый OTP, ответственность, каталог и дашборд.
- Регистрация тестового производителя, очередь приглашения, подтверждение email, имя/фамилия и установка пароля, стартовая страница производителя.
- Ссылки приглашения и сброса на 72 часа; восстановление из другого браузерного сеанса с новым входом BFF. Старый пароль отклоняется, новый работает.
- Пауза отправки OTP, запрет повторного использования кода и изменяющих запросов без Origin/Referer.
- Реальный worker отзывает прежние сеансы и доверенные устройства после смены пароля; новое устройство снова требует код.
- Выход BFF завершает сеанс Keycloak и возвращает локальную страницу без токенов в URL. Реальный подписанный backchannel logout отзывает сеанс и сохраняет запрет повторного использования sid.
- Публичный backchannel endpoint отвечает 404, включая конечный слеш, изменение регистра и query string. Внутренние уведомления Keycloak проходят проверку подписи.
- В браузере проверены формы входа, восстановления и регистрации на shadcn/ui, смена языка и отсутствие ошибок консоли. Матрица экранов темы отдельно проверена в мобильном и широком представлениях.
- Realm sync сохраняет дополнительные атрибуты клиента, пользователей и секреты. Directory mount и reload Caddy применяют заменённые при загрузке конфигурационные файлы.

Тестовые аккаунты, профили, identities, sessions и письма удалены; оставшихся тестовых аккаунтов — 0. Неизменяемый аудит сохранён. Отдельная тестовая БД и её временные реквизиты удалены; данные работающего стенда сохранены.

## Реальная почта и границы проверки

Пользователь подтвердил первое письмо Azure SMTP во входящих Gmail. Личное приглашение администратора затем успешно отправлено через очередь. Пароль задаёт сам получатель; завершение его личной регистрации агентом не выполнялось. Автоматические тесты использовали `.local` и не расходовали внешнюю почтовую квоту.

AUTH-07 (трёхмесячная неактивность), полные кабинеты ролей, нагрузочная проверка и восстановление резервных копий остаются последующими этапами. Порядок — в [development-roadmap.md](../development-roadmap.md).
