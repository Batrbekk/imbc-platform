# Чтение Adata при создании профиля производителя — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** когда у зарегистрированного производителя появляется профиль (пароль установлен, MAN-03), worker один раз читает «Полную информацию» Adata по его БИН, хранит ответ и девять предзаполняемых значений с источником и временем чтения, а страница `/profile` показывает производителю состояние чтения и полученные значения. Настоящий коннектор по спецификации, не макет; в тестах — заглушка, реальный вызов — только ручной шаг владельца.

**Architecture:** планировщик `AdataScheduler` ставит задание pg-boss `adata-prefill` в одной транзакции с записью попытки — по событию установки пароля из уже работающего опроса событий Keycloak и, вторым входом, при первом входе в OIDC callback; оба входа идемпотентны. Задание worker `AdataPrefillJob` резервирует единицу квоты периода атомарным SQL, делает один Get Request и опрашивает Check Request до общего срока; сбой источника — состояние попытки, а не исключение. Хранение — таблицы DBML `external_check` и `external_check_attempt` плюс две наши: `prefilled_value` (источник и время каждого значения) и `adata_allowance` (счётчик периода); миграция только expand. Чтение — `GET /api/v1/profiles/own/adata` под существующим `profile.read`, только организация сеанса.

**Tech Stack:** TypeScript, zod 4, NestJS 12, Drizzle ORM 0.45, PostgreSQL 18, pg-boss 12, nestjs-pino, Node `fetch`, React 19 + Vite, TanStack Query, use-intl, shadcn/ui на Base UI, vitest.

**Spec:** `docs/analyst/2026-11-11/specification-v1.3.md` — 5.1 (MAN-01…MAN-05, особенно MAN-03), начало 5.2 (MAN-06, MAN-07, MAN-08), MAN-09…MAN-11, MAN-17, MAN-21; 6.5 (IMBC-07; IMBC-10…IMBC-14 — вне среза); 6.6 (EXT-01…EXT-05); 8.2 (NOT-23); 9.1 (записи «External check», «Due-diligence record»; DATA-01…DATA-03, DATA-08); 11 (NFR-06, NFR-10, NFR-12); раздел 4 (GEN-08, GEN-11, ADM-06). Заметки `docs/handoff/adata-integration-notes.md`; DBML `docs/analyst/2026-11-11/imbc-platform.dbml` (`external_check`, `external_check_attempt`, `due_diligence_*`, `main_information`, `shareholder`); `docs/development-roadmap.md` — этапы 1, 4а, 4б, §4.2, §9.

```ts
export const ADATA_FAILURES = ['network', 'timeout', 'http_4xx', 'http_5xx', 'module_off', 'rejected', 'malformed', 'interrupted'] as const;
export type AdataFailure = (typeof ADATA_FAILURES)[number];
/** Ошибка без URL, тела ответа и cause: message = `adata ${failure}` (+ HTTP-статус). */
export class AdataCallError extends Error { constructor(readonly failure: AdataFailure, readonly httpStatus: number | null) }
export interface AdataTiming { firstPollDelayMs: number; pollIntervalMs: number; deadlineMs: number; requestTimeoutMs: number }
/** Заметки: опрос раз в 5–10 с, ответ до 90 с. Срок — 120 с от Get Request (90 + запас). */
export const ADATA_DEFAULT_TIMING: AdataTiming = { firstPollDelayMs: 5_000, pollIntervalMs: 5_000, deadlineMs: 120_000, requestTimeoutMs: 15_000 };
export class AdataClient {
  constructor(opts: { baseUrl: string; token: string; requestTimeoutMs: number; fetch?: typeof fetch });
  /** Get Request `GET /api/company/info/{token}?iinBin=` — единственный вызов, расходующий квоту. */
  startCompanyInfo(bin: string): Promise<{ pollToken: string }>;
  /** Один Check Request `GET /api/company/info/check/{token}?token=`. */
  checkCompanyInfo(pollToken: string): Promise<{ ready: false } | { ready: true; data: Record<string, unknown> }>;
}
/** Опрос до deadlineAt; временные сбои (network, timeout, http_5xx) не прерывают опрос до срока. */
export function pollCompanyInfo(client: AdataClient, pollToken: string, o: { deadlineAt: number; timing: AdataTiming;
  now?: () => number; sleep?: (ms: number) => Promise<void> }): Promise<{ ready: true; data: Record<string, unknown> } | { ready: false; failure: AdataFailure }>;
/** JSON-копия value, где токен и encodeURIComponent(token) заменены на '[redacted]'. */
export function redactToken<T>(value: T, token: string): T;
```

Решения клиента: путь собирается `new URL(\`/api/company/info/${encodeURIComponent(token)}\`, baseUrl)` + `searchParams`; `AbortSignal.timeout(requestTimeoutMs)`; любой отказ `fetch` (в том числе с `cause`) → `AdataCallError('network' | 'timeout')` без `cause`; объект `Response` и его `url` никуда не передаются. Get Request: 200 и непустая строка `token` → ок; 200 без `token` или `success:false` → `rejected`; 403 с `message: "modules not connected"` → `module_off`; прочий 4xx → `rejected`; 5xx → `http_5xx`; тело не JSON → `malformed`. Check Request: 200 `message:"wait"` → не готово (`success:true` не означает готовность — смотреть `message`); 200 `message:"ready"` и `data` — объект → готово; `ready` с `data` не-объектом или тело не JSON → `malformed` (опрос прекращается); 400 → `http_4xx` (прекращается); 5xx и сеть — временные. Срок истёк: последний ответ был `wait` → `timeout`, иначе — последний временный сбой. Тело ошибочного ответа не читается дальше `message` и не хранится.

**Разбор** (`company-info.ts`, чистые функции): `companyInfoDataSchema` — `z.looseObject` по блокам `basic`, `kzCoContact`, `founders` (поля `z.unknown()`, блок может быть `null` или отсутствовать); `extractPrefill(data): PrefillRow[]`, `PrefillRow = { field: PrefillField; position: number; value: string; label: string | null }`. Общее: строки `trim`, пустые и дубли значения в поле отбрасываются, число → `String`, не больше 50 строк на поле.
