## Параллельная работа

Координатор объединяет код, миграции, проверки и поставку. Агенты ведут backend/data и UI/browser в отдельных границах; **GPT-6 Astra** независимо проверяет права, бизнес-поведение, гонки и доказательства приёмки. Сейчас координатор публикует проверенные записи и объединяет новый файловый контракт; агент интерфейса готовит общие DTO и UI без scan; backend-агент реализует storage/migration/API cutover; Astra независимо проверяет их. Backend AGAR/CDP и заметок оператора принят в отдельных границах; их общая композиция и UI следуют после файловой дельты. Следующие задачи передаются по мере освобождения исполнителей.

Обследования зафиксированы в Git checkpoint `3eeab65`, внутренние записи — `5435d0d`; Azure этими checkpoint ещё не обновлён. На Azure промежуточный изолированный кандидат остаётся `6d13452` / SQL0025; его проверки не подтверждают работу новых SQL0026–0031. Процент закрытых checkbox и число тестов не переводятся в срок production: завершение зависит также от полной реализации оставшегося объёма и реальной приёмки.
